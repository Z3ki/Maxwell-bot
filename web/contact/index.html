Bugs and suggestions

Check existing GitHub issues first. If the problem isn't there, open a new issue with what you tried, what happened, and what you expected. Include the command name and a redacted screenshot or error if you have one.

Private privacy support

In Discord, open /config → Privacy → Request private support. This form sends your request privately to the configured application operator and reports delivery failures. Include the scope you want reviewed; do not send passwords, tokens or API keys. Use Delete my data for supported active stores. Published workspaces, backups and external copies need operator review.

The hosted operator must verify the support recipient and publish its responsible identity before public release. This release candidate has not completed that verification. Public GitHub issues are not a private support channel. Self-hosted instances have their own operator.

About the project

Maxwell is an independent, open-source project maintained by Z3ki. The hosted service is still in public alpha.
