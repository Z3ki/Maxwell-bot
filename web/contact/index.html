Something up?

Help us fix it. A little context makes a bug report much easier to use.

Bugs and suggestions

Check existing GitHub issues first. If the problem isn't there, open a new issue with what you tried, what happened, and what you expected. Include the command name and a redacted screenshot or error if you have one.

View project issues ↗

Privacy and deletion requests

Contact the hosted bot's operator through Discord where you use Maxwell. Include your Discord user ID and whether the request concerns a server, private conversation, stored memory, or published file. This site does not currently offer a private support form.

GitHub issues are public. Do not post passwords, API keys, private conversations, or other sensitive details there. If you self-host Maxwell, contact the operator of that instance.

About the project

Maxwell is an independent, open-source project maintained by Z3ki. The hosted service is still in public alpha. Maxwell Premium is in preparation and is not currently for sale.
