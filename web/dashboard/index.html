    How should Maxwell reply?

    Language and personality follow you across Discord. Reply defaults apply to commands and message actions.

    More reply options
    Privacy and saved history

    Current requests and necessary context are sent to the selected AI provider, including fallbacks. Provider retention is separate. Automatic learned facts and embeddings are retired.

    Off deletes saved conversation content. Tool workspaces, published content, previous provider copies and backups need operator review.

    Bring your own AI Optional

    Maxwell already includes AI. Connect a provider only if you want chat or Premium subagents to use your own API account.

    Subagents can use their own endpoint, key, model, reasoning, context and deadlines. Without a separate key they inherit your chat BYOK, then the operator worker default. Operator worker limits still apply.

    Persistent storage is part of Premium

    With Premium, Maxwell keeps your builds, downloads and pages in /storage, up to the operator’s limit (100 MB by default). The shell sandbox wipes /workspace after it idles; /storage stays.

    Premium is granted by the bot operator.

    Your public folder

    Files in public/ are served there. A folder with an index.html is a page: public/cat-3d/index.html → …/cat-3d/. Pages run sandboxed: scripts work, cookies and saved browser storage don’t persist.
