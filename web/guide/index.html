Quick guide

Less setup.
More conversation.

Start with one request. Adjust the rest when you need to.

Ask Maxwell

Where Maxwell is available in Discord, type /maxwell, fill in prompt, and send it. Attach a supported file or image when it helps explain your question.

Replies are public by default. Choose visibility: Private for a reply only you can see. Save Private in /config → Default visibility to turn public replies off for your future requests. An explicit visibility option overrides your saved default.

Make it yours

Open /config for a private menu with an overview of your choices. Select a setting, read what it does, and pick an option. Changes save immediately. Reset restores that setting's default.

Settings you can personalize
SettingWhat it changes
Default visibilityPublic replies in the channel, or private replies only you can see.
Response modeNormal answers, research, summaries, explanations, rewrites, translations, brainstorming, or code.
Web researchAutomatic search, always search, or no web search.
Answer detailQuick, balanced, or deep answers.
Channel contextNone, or the last 10, 25, or 50 accessible messages in this channel.
Language & reply styleYour preferred language and tone. Protected instructions and permissions still apply.
Bring your own keySelect a supported provider and model, save an encrypted key, test it, or delete it.

Change direction

Use /cancel in the same channel to stop your running request. It only cancels requests that belong to you.

Set up a server

Server owners and members with Manage Server can open the This server area in /config. Choose response channels, optional tools, capability groups, moderation, progress messages, and ticket greetings. These choices apply to that server; your personal reply settings apply to your requests.

Private requests cannot perform server-wide actions. Switch a request to Public when asking for an action that affects the server. Discord permissions and Maxwell's tool policies still apply.

Run your own Maxwell

The software is free under the MIT license. You'll need Docker, Git, curl, Python 3, an official Discord bot token, and a compatible model endpoint. Follow the installation guide for privileged Discord intents and provider setup.

SELF-HOST / SHELL
curl -fsSL https://raw.githubusercontent.com/Z3ki/Maxwell-bot/main/easy-install.sh | bash

Read the installer before running it. Linux is the primary target; on macOS or Windows, install Docker Desktop first.
