Add Maxwell

Pick where you want Maxwell. You can do both.

  • Add to a server to give everyone there /maxwell, the right-click apps and server tools. You need Manage Server in that server.
  • Add to your account to use Maxwell in DMs, group chats and servers that allow external apps.

Ask Maxwell

Type /maxwell, write your prompt, and send it. It works in servers where Maxwell is available and in DMs once you've added it to your account. Attach a file or image when it helps explain the question.

The command has a few optional settings for one request:

/maxwell options
OptionWhat it does
modeAsk, research, summarize, explain, rewrite, translate, brainstorm, or code.
webSearch automatically, always search, or skip the web.
detailBrief, balanced, or deep answers.
languageReply language for this request.
visibilityPublic in the channel, or private so only you see the reply.
contextHow many recent channel messages Maxwell reads, from none up to 1,000.
image / fileAn image or attachment for Maxwell to look at.

Replies are public by default. Pick visibility: Private for a reply only you can see, or save Private as your default in /config or the dashboard. An explicit option on a request wins over your saved default.

Right-click apps

Right-click a message (long-press on mobile), open Apps, and pick one:

  • Ask Maxwell: ask anything about that message.
  • Summarize: the short version of a long message or thread.
  • Explain: a plain-language explanation of code, jargon, or an error.
  • Fact-check: checks claims against real sources.
  • Rewrite / Translate: a cleaner or translated version.

Right-clicking a person also offers Ask Maxwell.

Make it yours

Open /config to set language, answer length, and reply visibility on the first screen. Choices save immediately. Personality sets your tone, Privacy chooses whether your messages are saved, My AI provider connects your own key, and More options covers search and recent-message context. The Web dashboard button opens the same settings in your browser.

The dashboard

Run /dashboard in Discord. Maxwell replies privately with a sign-in link that works once and expires after 15 minutes. Open it and you're in. There is no password, and the session ends when you close the tab or press Sign out.

  • Overview: your plan, message allowance, storage use, and public folder address.
  • Reply settings: the same personal settings as /config.
  • AI connection: add, test, or remove your own provider key.
  • Files (Premium): browse your storage, upload, create folders, edit text files, rename, delete, and share signed links. Pick your public handle here too.
  • Schedules (Premium): create, pause, resume, edit, and delete wake-ups.
  • Servers: server settings for servers where you have Manage Server.

Treat the sign-in link like a password until it's used. If someone else opens it first, run /dashboard again for a fresh one.

Storage Premium

The code sandbox is a temporary Linux machine. It's wiped after about ten idle minutes. Premium accounts get a /storage folder with 100 MB that survives those wipes: Maxwell saves it before a reset and restores it on your next command.

  • Ask Maxwell to "save this in my storage", or have it build straight into /storage.
  • Files a subagent makes are copied to /storage/jobs/<job id>/ when the job finishes, so a finished build survives a reset.
  • Manage everything in the dashboard's Files page. A signed link shares one private file for a set time, from an hour up to 30 days.
  • Everything outside /storage is temporary.

Your public folder Premium

Everything inside /storage/public/ is published at your own address. Pick a handle in the Files page, or ask Maxwell to set one. Handles use lowercase letters, numbers, and single hyphens, up to 30 characters.

Example, handle 7up
/storage/public/cat-3d/index.html
→ https://maxwell.z3ki.dev/u/7up/cat-3d/

Each folder with an index.html works as its own page or game. Try "make a snake game and publish it as snake". Anyone with the link can open public files, so keep private things outside public/.

Schedules Premium

A schedule is a saved prompt plus a time. When it's due, Maxwell wakes up, runs the prompt as a background job, and posts the result in the channel where you made it, or in your DMs. You can ask in plain words ("every weekday at 9, summarize my repo's new issues") and Maxwell sets it up, or create one in the dashboard.

Schedule patterns
PatternRuns
0 9 * * 1-5Weekdays at 09:00
*/30 * * * *Every 30 minutes
0 18 * * 0Sundays at 18:00
@dailyEvery day at midnight
OnceA single date and time, or "in 45m"

Times use the timezone you pick (UTC unless you say otherwise). On the hosted bot you can keep up to 10 schedules, runs are at least 15 minutes apart, and there's a daily cap on total runs.

Subagents Premium

Long jobs such as websites, bigger code changes, research, or add-ons go to a subagent that works in the background while you keep chatting. Maxwell posts one short line when it's done and attaches the result. Use /tasks to see your jobs or cancel one.

Change direction

Use /cancel in the same channel to stop your running request. It only cancels requests that belong to you.

Set up a server

Server owners, administrators, and members with Manage Server can open Server settings in /config or the dashboard's Servers page. Choose response channels, allowed and extra tools, moderation, progress updates, and ticket greetings. These choices apply to that server; personal reply settings apply to each person's own requests.

Private requests can't perform server-wide actions. Switch a request to Public when you ask for something that affects the server. Discord permissions and Maxwell's tool policies always apply.

Your own AI key

In /config → My AI provider or the dashboard's AI connection page, pick a supported provider and model, save your key, and test it. Keys are stored encrypted, and you can delete them any time. Your requests then use your connection.

Music, games and voice

  • Music: join a voice channel and ask Maxwell to play something, or use /music in a server to play, queue, skip, pause, and turn on autoplay.
  • Games: "play chess with me" or "let's play checkers" starts a game in the channel.
  • Voice: ask Maxwell to say something out loud and it replies with speech.
  • Images: ask for a picture, or attach one and ask for an edit.

Run your own Maxwell

The software is free under the MIT license. You'll need Docker, Git, curl, Python 3, a Discord bot token, and a compatible model endpoint. On your own copy you choose the model provider, tools, limits, and who gets Premium.

Self-host
curl -fsSL https://raw.githubusercontent.com/Z3ki/Maxwell-bot/main/easy-install.sh | bash

Read the installer before running it. Linux is the main target; on macOS or Windows, install Docker Desktop first.
