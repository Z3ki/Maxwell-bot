Overview

What Maxwell does

01

Discord AI conversation

Maxwell joins Discord with an official bot token. In a server or a direct message it can take a turn on text, and on images, audio, video, and files you attach. Replies come from the OpenAI-compatible model configured for that install: Ollama, LM Studio, OpenRouter, OpenAI, or another compatible endpoint.

Channel chat and the /maxwell command are both ways to talk to it.

02

Scoped memory

Maxwell stores channel context and longer-term facts, including shared context with visibility controls. The /memory command manages that store.

On the hosted alpha, memory can be lost while the service changes. Keep secrets out of it.

03

Tools

When a reply needs an action, enabled plugins can search the web, generate or edit an image, moderate a server, play chess or checkers, publish a generated site, or run a sandboxed shell. Web search depends on its optional packages and configuration.

Destructive tools fail closed after the turn has taken in untrusted fetched content. They stay closed until a new user message.

04

Media in, conversation out

Bring images, audio, video, and files into the conversation when the configured model and host can read them. Audio attachments remain supported; Maxwell does not join voice channels, listen to calls, or speak aloud.

Replies stay in text or completed media artifacts. Model support and optional media-processing packages determine which attachments an install can understand.

Self-host

Install it on your machine

Use this when you want a Maxwell you run yourself. The easy installer clones the repository, asks for the minimum configuration, and hands off to Docker. It asks for an official Discord bot token, the model endpoint and an API key when the provider requires one, and optionally a Discord user ID for owner-only commands.

Linux is the primary target. On macOS and Windows, install Docker Desktop before you start. Create the bot in the Discord Developer Portal and enable the Message Content, Server Members, and Presence intents.

Shell

curl -fsSL https://raw.githubusercontent.com/Z3ki/Maxwell-bot/main/easy-install.sh | bash

Have this ready

  • An official Discord bot token from the Developer Portal.
  • Privileged gateway intents: Message Content, Server Members, and Presence.
  • Git, curl, and Python 3 on the setup machine.
  • Docker Engine with Compose, or Docker Desktop.
  • An OpenAI-compatible model endpoint.

The installation guide covers those intents, the full installer, and unattended setup. Read easy-install.sh before you pipe it to a shell.

This website

The hosted bot is a public alpha

The bot on this website is the operator’s hosted instance. A bot you install with the command above is yours. The hosted service is in public alpha while a premium release is in preparation.

During alpha, expect bugs, downtime, and lost memory. Usage limits can change. The hosted alpha is free to use within those limits. Billing stays off while the premium release is in preparation.

The source is MIT licensed and free to self-host. If you already talk to the hosted bot, the terms and privacy policy apply to that instance.
