Privacy Policy

What the hosted Maxwell service processes, where it goes, and the choices you have.

Last updated 8 October 2026

The short version. Five things worth knowing about your data:
  • Your messages go to AI providers. What you send Maxwell — including attachments — is forwarded to the operator-configured AI provider so it can reply.
  • Data stays on the operator's server. Everything is stored locally in SQLite databases and JSON files. No cloud analytics, no advertising trackers, and your data is never sold.
  • History is kept, not forgotten. Rolling conversation history and logs stay until the operator clears them.
  • Deleting is manual for now. There is no self-service delete button yet. Ask via the Contact page and the operator will delete your data.
  • Not for under-13s. Discord requires users to be at least 13, and so does Maxwell.

1. Who this covers

This policy explains how data is handled when you use a hosted Maxwell instance: the Discord bot, its website, and any related APIs it provides. Throughout this policy, "the operator" means whoever runs this Maxwell instance — the responsible party for its data.

This policy does not cover copies of Maxwell that other people host themselves. If you use someone else's instance, or run your own, that operator's own policy applies instead. It also does not cover Discord itself or any third-party service Maxwell connects to; those have their own policies.

2. What data is collected

Depending on how you use the bot, the operator processes:

  • Discord identifiers: your user ID, username, and display name
  • Message content the bot can see: the text of your requests and, if you enable channel context, recent messages in the channel
  • Server, channel, and message IDs for the places Maxwell is used
  • Attachments and media you send: images, audio, documents, and other supported files
  • Optional saved preferences: things like language, reply style, answer detail, context size, and reply visibility, stored against your Discord user ID
  • Bring-your-own-key (BYOK) provider keys: if you save your own AI provider key in the settings, the provider name, model choice, and the encrypted API key are stored against your Discord user ID
  • Conversation context and memory the bot keeps so later replies make sense
  • Content you ask Maxwell to create or publish, such as generated text, images, or sites
  • Operator-side logs and usage counts: timestamps, request metadata, tool activity, error reports, and counted usage used to show the usage meter and enforce limits

3. How it is used

The operator uses this data to:

  • respond to you — generate the replies and tool results you ask for
  • keep conversation context and memory — so follow-up questions make sense and saved facts can be recalled
  • prevent abuse and keep the service safe — enforce the Terms of Service, investigate errors, security issues, and misuse, and comply with legal obligations
  • count usage — calculate usage-meter percentages and apply current limits

Your data is not used for advertising, and it is not sold.

4. AI processing

Maxwell is not an AI by itself — it sends your request to a real AI model to get an answer. To produce a reply, message content is sent to the operator-configured third-party LLM provider, together with whatever context that turn needs (recent messages you enabled, saved memory, attachments, and tool results). The provider receives what the bot sends and processes it under its own terms and privacy policy.

For ordinary requests, the operator's own provider key is used — you don't need an account with the AI provider.

Bring your own key. If you save your own provider key in the settings, your requests go to that provider using your key. BYOK keys are encrypted at rest and used only for that user's requests — never for anyone else's traffic, and not for the operator's own key. You can delete your saved key at any time in /config.

A private reply is not private processing. Choosing Private in Maxwell only hides the reply in Discord. The request is still processed by Maxwell and its configured providers exactly as described here. Keep passwords, private keys, and other people's private information out of your requests.

5. Where data lives

Everything above lives on the operator's own server, in Maxwell's data directory — SQLite databases and JSON files on the machine that runs the bot. There are no cloud analytics services, no advertising trackers, and no third-party dashboards holding a copy of this data. Your data is not sold, and it is not shared with advertisers or data brokers.

6. Retention and deletion

Rolling conversation history and logs are kept until the operator clears them. Memory, preferences, usage records, and operational logs stay as long as they are useful for running the service, and are deleted or overwritten when the operator rotates or clears storage. Third-party providers may keep their own copies under their own policies.

Self-service deletion is not available yet. There is no delete button or delete command at the moment. To have your data deleted, request deletion via the Contact page and include your Discord user ID — that ID is how the operator finds your data. The operator will delete it. Deletion from active storage may not remove copies already held in routine backups or in third-party provider logs.

7. Security

The operator takes reasonable precautions: saved API keys and other credentials are kept in encrypted credential storage rather than plain text, tool and shell workloads run in container sandboxing, and access controls limit who and what can reach the data directory and the bot's systems.

That said, honestly: no system is perfectly secure. No method of storage or transmission over the internet can be guaranteed to be 100% safe, so the operator cannot promise absolute security.

8. Third parties

These services receive the data needed to do their part of the job, as described above:

  • Discord — delivers your messages and displays replies; Discord has your messages already
  • AI/LLM providers — the operator-configured model provider(s), which receive prompts, context, and attachments to generate replies and embeddings
  • Search providers — SearXNG, Tavily, or ddgs, when web research is used; they receive the search query
  • Image and text-to-speech providers, when those tools are used
  • The host and network that runs the bot

Each processes data under its own terms and privacy policy. The operator may also disclose information if required by law, or to stop abuse or protect people from harm.

9. Your rights

You can access the data stored about you, ask for it to be corrected if it is wrong, ask for it to be deleted, and ask for a portable copy of it. Make any of these requests through the Contact page and include your Discord user ID. The operator will respond and act on valid requests.

EU and UK (GDPR-style rules). Where these rules apply, the legal bases for processing are performing the service you asked for (and steps at your request before it) and the operator's legitimate interests in running, securing, and maintaining the service. You also have the right to object to or restrict certain processing and to lodge a complaint with your local data-protection supervisory authority.

California (CCPA/CPRA notice). In the past twelve months, the service collects the categories of personal information described in section 2 — identifiers (Discord user IDs, usernames), user content (your messages and attachments), and internet or network activity (usage counts and logs) — for the business purposes in section 3. Personal information is not sold and is not shared for cross-context behavioural advertising. California residents have rights to know, delete, and correct their personal information, and will not be discriminated against for exercising them.

Exercising any right does not affect your other rights, and some requests may be limited where the law requires keeping certain records.

10. Children

The service is not directed at children under 13 (or the higher minimum age in your country). Discord itself requires users to be at least 13, so you must meet that requirement to use Maxwell at all. The operator does not knowingly collect personal information from children under 13. If you believe a child under 13 has used the service, say so via the Contact page and the operator will delete that data.

11. International transfers

Your data may be processed wherever the operator or their AI provider operates. The server, the operator, and third-party providers may be in a different country from you, so data can leave your country and be handled under different data-protection rules than you are used to. By using the service, you understand this.

12. Cookies

The static site sets no cookies — no analytics, no tracking, no advertising identifiers. The operator's API uses HTTP Basic authentication only, so it sets no session or tracking cookies either.

The optional settings dashboard uses essential, host-only login cookies. Discord sign-in provides your user ID, display name and server memberships/permissions so the dashboard can show your account and servers you may manage. Discord access tokens are encrypted in server-side session storage and are never stored in browser local storage. Sessions last at most eight hours and signing out removes the session. Personal API keys are encrypted separately and can be removed in the dashboard or /config.

13. Changes

This policy may change from time to time. The current version is always the one on this page, with its "Last updated" date at the top. Significant changes will be posted here before they take effect where the law requires it.

14. Contact

Questions about privacy, or requests to access, correct, export, or delete your data, go to the operator of this Maxwell instance through the Contact page. Include your Discord user ID so the operator can find your data. For public project issues there is also the source repository — never post private data there. See also the Terms of Service.
